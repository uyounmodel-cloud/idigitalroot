# Motion successor — architectural security delta

The existing UNIVERSAL_THREAT_MODEL and all 151 owner-title / 345 ASVS rows remain applicable; prior partial/external controls are not promoted. This visual successor changes code-owned public markup/CSS and an isolated browser motion module. No dependencies, Worker bindings, APIs, schema, authentication, authorization, inquiry fields, analytics consent, media reader or CMS executable-content policy change.

Data flow: published D1 content -> server-side bounded reader/renderer -> public HTML + same-origin self-hosted CSS/JS/fonts -> decorative browser animation. Protected preview -> same renderer/CSS under existing no-store/capability/script-src-none boundary. Motion never fetches or submits data. Two localStorage enum preferences are presentation-only and are not identities, authorization, entitlements or consent.

Assets: published content integrity, private drafts/preview capability, inquiry PII, browser responsiveness and accessibility. Actors: visitor, keyboard/touch/screen-reader visitor, reduced-motion visitor, CMS editor, malicious content submitter and hostile third-party scripts. Trust boundaries and entry points remain the server/API/preview boundaries already documented. Additional inputs are pointer position, intersection state, scroll position and an allowlisted preference. These inputs only set code-owned style numbers or enum attributes; no HTML insertion, remote fetching, evaluation or selectors derived from CMS content.

Abuse/failure cases: motion discomfort -> OS reduced-motion ceiling + visible keyboard pause + static/no-JS fallback; broken storage -> caught without blocking rendering; script failure -> content visible by default; excessive CPU -> CSS transform-only looping sculpture, offscreen pause, fine-pointer-only tilt with one queued rAF, no global animation loop/scroll capture; layout shift -> server-rendered dimensions, reserved aspect ratio and self-hosted fonts; stale content bindings -> keep heading/paragraph field order and verify exact editorial schema equality; preview divergence -> identical generated CSS, static protected preview by design; data loss -> copy only compatible stopped ROOT02 review data into a separate candidate, preserve original byte inventory, never publish automatically. No fake account/production functionality is added by the animation.
