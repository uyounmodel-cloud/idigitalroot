# Phase 5 Client Public Website Factory Plan

1. Freeze a generic client public-site runtime architecture compatible with the reusable Client CMS.
2. Define supported layout/components/design tokens and module contracts.
3. Define Website Blueprint → site profile → CMS schema → public renderer mapping.
4. Define master client-discovery brief/template.
5. Define Codex prompt pipeline for product brief, IA, content model, visual direction, implementation and QA.
6. Create at least two materially different reference site profiles to prove genericity.
7. Prove EN/AR RTL and multi-locale support.
8. Prove isolation between sites/deployments/data/media/auth.
9. Create generated-site security/quality gate that rejects unsupported or unsafe output.
10. Create immutable release/deploy package template per website.
