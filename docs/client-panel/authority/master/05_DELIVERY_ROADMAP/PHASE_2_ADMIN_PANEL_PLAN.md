# Phase 2 Admin & Operations Plan

1. Re-validate the foundational Admin blueprint against Phase 1 final contracts.
2. Freeze module/domain ownership and API boundaries.
3. Build staff IAM: invitation, MFA/passkey path, roles, permissions, scope, sessions, re-auth, audit.
4. Build lead/inquiry operations.
5. Build clients, websites/Digital Roots and project orchestration.
6. Build Website Blueprint/onboarding-template administration.
7. Build services/plans/subscriptions/domains/email/support.
8. Build commercial/billing modules only with explicit product/legal/accounting rules.
9. Build localization/provider/dependency registry.
10. Build security/audit/session/feature-flag/settings modules.
11. Build environment/deployment/job/backup monitoring controls through narrow privileged service contracts; do not expose raw secrets.
12. Integrate with dedicated Public CMS via explicit orchestration links/contracts, not by merging apps.
13. Run Admin-specific high-assurance security closure.
14. Owner review and independent release gate.
