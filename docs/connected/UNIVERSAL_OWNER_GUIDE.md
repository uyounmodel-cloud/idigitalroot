# Open ROOT 02

Download the new ROOT 02 review ZIP from the repository downloads folder, extract it into a new folder, close an earlier preview launcher, and double-click OPEN_CONNECTED_PREVIEW.cmd. Keep its window open. The website and CMS show ROOT 02 so you can confirm the correct build. First startup verifies offline dependencies and builds in native Ubuntu/WSL storage; it prints progress. Do not open an old extracted package or overwrite an existing candidate's files.

Website: start at the company homepage, choose Students / Employees & Professionals / Entrepreneurs & Startups / Businesses & Organizations. Each audience has one complete story page. “Start my … Root” opens the real quote wizard with an editable audience choice. Your team prepares the quote; there is no automatic signup or payment. Browse shared services, How We Work, account plan and published Knowledge.

CMS: sign in for local owner review; this uses local test identity, not production Cloudflare Access. Pages -> choose the audience or shared page -> Open & edit. Select a section, edit the filled-in words/photos/button, then Save & preview. The saved preview is private. Publish… names the page and language; review its checkbox and confirm only when ready. English and Arabic publish separately. CMS interface language and preview language remain independent.

Menus & footer -> Edit main menu -> add a human label and an existing page destination -> Save navigation draft. A saved-draft bar appears immediately. Preview your saved menu; choose system/light/dark appearance to match your website view. The preview menu opens at phone/tablet widths without enabling scripts. Close the preview; Publish… is a separate, explicit step. Saving or previewing does not publish.

Articles -> New article -> edit the title/body and categories -> save and inspect -> explicitly review/publish. Only published articles appear in Knowledge and search. Services manages published service titles/descriptions/availability; page editing manages the foundation story. Menus, footer, media, translations, appearance and brand settings keep their own scoped publication controls.

ROOT 02 starts a separate review dataset because its structure is new. Earlier review folders and drafts are preserved, not automatically imported over the new structure. Reopening this same ROOT 02 package retains its own saved edits. Keep your older extraction if you want to inspect its drafts; close one launcher before opening another. Do not copy raw databases between the different content layouts.
