# Focused CMS and frontend refinements — 15 October 2026 (Asia/Beirut)

Candidate, not owner-approved. Latest owner direction: make the CMS much simpler, richer and cleaner; repair frontend errors; visual improvements are authorized while preserving content and its distribution. This supersedes the previous strict restoration-only presentation constraint. Historical approvals and originals remain preserved.

The ordinary editor now uses two steps: **Edit content → Save & preview → Publish**. The form and full saved website preview occupy separate views. The media library now has named cards and protected thumbnails for approved raster photos, instead of blank picture boxes. Fields are larger, section names describe their purpose, section search finds long-page content quickly, and phones use an ordinary section dropdown. Extra section settings and the extra-tools navigation remain collapsed until requested. English/Arabic interface, editing language and preview language remain independent. Content-field direction follows the edited language; URL fields stay left to right. Removing a page’s last added section returns to its page details. Same-screen settings publication and all 27 CMS workspaces remain available. No new capability is claimed for inherited advanced features whose external gates remain open.

Saving stays explicit. Save & preview saves dirty fields through the existing version-checked server writer, then displays that exact saved draft. Switching back to Edit alone does not write or publish. Unsaved-navigation guards, exact reviewed revision checks, publication pointer CAS, permission enforcement, preview expiry/revocation and existing frozen rollback review rules remain. There is no autosave, automatic publication, new signup, edition selector, schema change or provider mutation.

The new enterprise visual system uses a framed architectural hero, bounded ecosystem graphic, restrained jade/cyan light, consistent navigation/buttons, refined typography and coherent cards across product/editorial/inquiry routes. It includes distinct Toolbox and Workspace surfaces within the same system and EN/AR light/dark responsive treatment. No text, chapter or product position is removed.

Frontend fixes: initially hidden/empty notifications, actual persistent header wrapper, tablet navigation breakpoint, nonoverlapping hero artwork, more consistent spacing/readability, search-dialog background isolation with focus restoration, desktop Personal-menu Escape behavior, focus/scroll preservation after Workspace/Major concept-tab changes, and restoration of language/theme/search/client controls that the published mobile menu had dropped. Additional CMS sections on existing supporting pages are now rendered after their existing content, rather than saved invisibly. Searchable All page text helps locate copy on supporting pages. Concept tools remain clearly marked demos, not operating client tools.

Section-photo defect: previously a photo reference could replace a protected section template, and the first referenced page image could be inserted into the hero regardless of its section. The new binding retains the existing template and attaches only that section's selected, server-approved local image. Other sections and the opening artwork remain intact. Removing a section photo creates a draft revision; it never deletes media. Empty approved-media selection gives a clear next step. Safe Worker URLs, approved/reference checks and private preview media capabilities remain in force.

New regression checks compare the exact rendered code-owned markup for all 134 localized route templates against rc4. No copy, chapter order or content placement is removed. Existing publication can intentionally change content through the CMS; that behavior remains tested. All server domain source, schema files, dependencies and locks remain unchanged.

See CLARITY_SECURITY_REVIEW.md, CLARITY_READING_CHECKPOINT.md and the current verification report for evidence and limits. Automated and agent visual review do not constitute owner usability acceptance, independent security acceptance or production readiness.
