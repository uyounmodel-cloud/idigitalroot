# Edit your website — 15 October 2026 (Asia/Beirut)

1. Open the CMS and choose **Edit the homepage**, or **Pages → Edit page**.
2. Choose the language beside **Editing language**. English and Arabic are saved/published separately. The top language buttons change the CMS interface only. Text fields follow the content language even when the interface uses the other language.
3. Choose what to edit in **On this page**. Search by section name. On a phone, use **What would you like to edit?**
4. Change the filled-in text. To change the opening paragraph, choose **Page title & introduction**. For its main button, choose **Opening section → Main button**.
5. Click **Save & preview**. This saves privately and opens the saved website design. Preview language and phone/tablet/desktop size are available here. Links/forms in this protected preview are inactive; use the connected public website to test them.
6. Return to **Edit content** if you want more changes. To finish, choose **Publish…**, check the named page/language/destination, tick the review box and confirm. In this review package, publishing affects the local website on your computer only.

**Save draft** keeps a private copy without entering Preview. Nothing is made public until you publish. If another person changes the same page, reload and review their changes; a stale editor cannot overwrite or publish them silently.

On supporting pages, open **All page text** and search for the words you want to change. Extra sections you add appear after the existing page content.

For a section photo, first use **Photos & files** to upload, review and approve a photo. Return to the section and choose **Choose a photo**. It stays inside that section. **Remove photo from section** does not delete the media file. Additional content, visibility, moving, copying and removing sections are under **More section options**. Safe text formatting remains available in rich-content sections; template text retains its website formatting.

Use the sidebar for menus/footer, services, articles and reports. Other features remain under **More website tools**, **Settings & team**, or **Find anything**. If a feature depends on an external provider or legal approval, the local review does not imply it is production-ready.

Keep the launcher window open while browsing. To stop, return there and press Enter. Compatible earlier local review edits are copied into a separate new-candidate folder; originals remain. Never delete the local data folder to resolve an issue. This package has not been deployed to Cloudflare.
