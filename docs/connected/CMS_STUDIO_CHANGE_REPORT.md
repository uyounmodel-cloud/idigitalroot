# Owner-directed Website Studio UI rebuild — 15 October 2026

Replaces the CMS navigation, home, page library and editing workspace, with a newly written interface stylesheet shared by all retained workspaces. This is a review candidate, not a transferred approval. The owner explicitly authorized the CMS redesign and selected restoration of the approved v4.3 public design.

- Seven everyday navigation areas; remaining permitted tools grouped by task, searchable by human names. No fake multi-audience selector: Student website is the currently connected edition.
- Task-focused home and searchable/filterable page list; secondary page operations use native disclosure menus. Existing creation, duplication, move, archive/restore and bulk operations remain available.
- One editing screen: section list, actual saved-revision website preview and editing form. Full Arabic RTL puts navigation/tree right and editor left. Phone layout places editable fields ahead of the long preview. CMS interface, editing and preview languages remain independent.
- Save, private preview and explicit publication together. The publisher confirms exact content/language/destination. Review creates an immutable READY clone; the client uses that returned entity/locale-bound revision, not a refreshed latest revision. Stale draft and public pointer conflicts fail closed.
- Homepage section shortcuts open their selected section; the Page editor navigation returns to a website page rather than a previously selected settings/legal record. Section choices and limits follow the unchanged canonical server registry, with a parity gate and safe text-section default.
- Existing template text appears directly in filled-in text fields, rather than blank generic placeholders and a closed extra-fields panel. Hero title/introduction stay synchronized with page details, and its main button label/destination now bind through the shared safe renderer without changing action code or layout.
- Inline safe rich-text formatting instead of ordinary-editor HTML source. Approved media, section visibility/order/add/remove/duplicate, structured item fields, history and existing specialized workspaces retained.
- Unsaved changes offer Save & continue / Keep editing / Leave without saving; browser unload warning and Ctrl/Cmd+S. Refresh/device/preview-language controls do not discard editing fields. Saved specialized settings acquire nearby preview/publish controls bound to the saved target and language.
- Protected HTML previews are now embeddable only by the same origin. Script/form execution remains disabled with CSP and iframe sandbox. The outer CMS remains unframeable. Capabilities remain scoped, short lived, revocable and private/no-store/noindex.
- Restores the approved public HTML style blocks with the inherited one-character transition parser correction. Removes the added hero depth, hover elevation and header blur. Connected-only styles and the prior narrow text/brand-accent contrast corrections remain; inquiry, consented analytics and published-content binding remain connected. Source HTML authority itself stays unchanged.

The initial browser pass caught the immutable review-clone integration and RTL grid placement; both were corrected. A rollback trial exposed the existing frozen locale-review guard. A provisional server-side relaxation was rejected during development because the frozen database triggers intentionally retain that guard; the final server authorization/publication implementation is unchanged. The interface now explains the required explicit review rather than approving drafts silently. Provisional test output is not final candidate evidence.

Fresh-extraction verification also exposed an inherited runner assumption that an empty evidence directory already existed. The runner now creates its own output directory before browser checks; no test assertion was removed.

No migrations, provider bindings, secrets, production resources or deployment changed. Full Toolbox/Student Workspace remain commercial-release requirements and presentation demos here; Admin/Client operational phases remain unopened. Future audience edition operations remain a documented architecture, not an implemented selector. Existing legal/provider/security/manual/independent release gates remain open.
